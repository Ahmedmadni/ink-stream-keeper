# MemoFlow — مذكرات، مهام، خزنة

تطبيق عربي باتجاه RTL، بثلاثة أقسام أساسية: المذكرات، والمهام كقائمة تحقق مع تفاصيل داخل كل مهمة، وخزنة كلمات المرور. واجهة هادئة مستوحاة من أسلوب Apple بخط **IBM Plex Sans Arabic** مضمّن داخل المشروع.

نسخة أندرويد تُحمّل الواجهة المضمّنة في APK، وتدعم OAuth العائد إلى التطبيق، واستعادة كلمة المرور، وقفلًا إلزاميًا قبل عرض البيانات، وخدمة Autofill أصلية. أُضيفت نسخ احتياطية مشفّرة تحفظ آخر سبع نسخ محليًا ويمكن ربطها بمجلد Google Drive من منتقي أندرويد. تفعيل بيانات النسخ يحتاج تطبيق تحديث قاعدة البيانات كما في [دليل النسخ والاستعادة](docs/BACKUP-V1.md).

- [ما نُفّذ وما تبقّى](docs/MEMOFLOW-IMPLEMENTATION-STATUS.md)
- [ملاحظات المنتج القديمة، للأرشيف فقط](docs/LEGACY-PRODUCT-NOTES.md)

المذكرات تحفظ الآن مسودة محلية أثناء الكتابة، مع حفظ متسلسل إلى الخادم وتنبيه عند اختلاف نسخة جهاز آخر. هذا لا يجعل التطبيق مستقلًا عن الإنترنت: تسجيل الدخول والتحميل الأولي ما زالا يعتمدان على الخادم. المسودات المحلية تخص المذكرات فقط، ولا تخزن مفاتيح الخزنة أو كلمات مرورها.

المهام تدعم الآن التصنيف وقائمة تحقق فرعية. تعرض القائمة تقدم البنود، وتكتمل المهمة الأساسية تلقائيًا عند اكتمالها. يحتاج السلوك المضمون في قاعدة البيانات إلى تطبيق [تحديث تصنيفات المهام وقوائم التحقق](docs/TASK-CATEGORIES-CHECKLISTS.md).

## التشغيل والتحقق

استخدم Node.js 22.12 أو أحدث ضمن إصدار مدعوم، وBun 1.3.9. ملف القفل المعتمد هو `bun.lock`؛ أُزيل `package-lock.json` القديم لتجنّب تثبيت شجرة حزم مختلفة.

```sh
bun install --frozen-lockfile
bun run dev
```

```sh
bun run typecheck
TZ=Asia/Riyadh bun run test
bun run build
bunx playwright install chromium
bun run test:browser
```

اختبار المتصفح يبدأ خادمًا محليًا على المنافذ 4173 و4174 و4175 ويستخدم بيانات اصطناعية، مع اعتراض طلبات Supabase ومنع الشبكة الخارجية. لا يكتب في حساب مستخدم حقيقي. تُحفظ صور التحقق في `.qa-results` محليًا فقط. يمكن تحديد متصفح مثبت عبر `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

## تنظيم الملفات

| المسار                                  | المسؤولية                                                        |
| --------------------------------------- | ---------------------------------------------------------------- |
| `src/routes/_authenticated/*.index.tsx` | قوائم الأقسام، منفصلة عن صفحات التفاصيل                          |
| `src/routes/_authenticated/*.$id.tsx`   | تفاصيل العنصر                                                    |
| `src/features/backup`                   | صيغة النسخ المشفّرة، التحقق والمرفقات، الاستعادة وشاشة الإعدادات |
| `src/services/files.ts`                 | حفظ ملف النسخة على الويب أو Documents ومشاركته أصليًا على الهاتف |
| `src/services/native-backup.ts`         | إعداد النسخ الدوري المحلي ومجلد Drive على أندرويد                |
| `src/components/AppLockGate.tsx`        | منع عرض البيانات قبل فتح رمز التطبيق                             |
| `src/features/notes`                    | حفظ المذكرات المتسلسل، المسودات المحلية، والتحقق من إصدار الخادم |
| `src/features/tasks/task-rules.ts`      | التصفية، اليوم المحلي، وتكرار المهام                             |
| `src/features/vault/session.ts`         | جلسة مفتاح الخزنة المقيدة بالحساب                                |
| `src/components/VaultSecurity.tsx`      | القفل عند إخفاء الصفحة والخمول                                   |
| `src/assets/fonts`                      | ملفات IBM المحلية وترخيص OFL                                     |
| `src/lib`                               | الوصول الحالي إلى Supabase والمنطق القديم الذي يُنقل تدريجيًا    |
| `tests`                                 | اختبارات القواعد وجلسة الخزنة وتدفقات المتصفح                    |

الخطط والمشتريات ومساحات العمل القديمة متاحة من الإعدادات، ولم تُحذف بياناتها. إعداد Capacitor الحالي يستخدم حزمة SPA محلية ولا يعتمد على نسخة واجهة منشورة قديمة.
