# Memo Flow

الاسم المقترح: Nuktah (نقطة) أو MemoFlow أو MySpace Notes

الهدف:
توفير تطبيق سريع وآمن ومتطور لتدوين الملاحظات وإدارة المهام والأفكار، مع دعم كامل للغة العربية، وتجربة استخدام ممتازة على الهواتف والأجهزة اللوحية.

1) المبادئ الأساسية للتصميم

 تصميم Material Design 3 حديث.

 دعم كامل للغة العربية (RTL) والإنجليزية (LTR).

 استجابة ممتازة لجميع أحجام الشاشات.

 واجهات بسيطة بدون ازدحام.

 انتقالات وحركات ناعمة.

 دعم الوضعين الفاتح والداكن.

 خطوط عربية احترافية مثل Cairo أو IBM Plex Sans Arabic.

 أيقونات واضحة ومتناسقة.

2) الشاشة الرئيسية (Home)

تتكون من:

 رسالة ترحيب.

 زر الإشعارات.

 صورة المستخدم.

بطاقات إحصائية

 إجمالي الملاحظات.

 المهام القادمة.

 المهام المكتملة.

 المفضلة.

3) صفحة إنشاء ملاحظة

تتضمن:

 عنوان.

 محرر نص غني (Rich Text).

 دعم العناوين.

 القوائم.

 التعداد.

 مربعات اختيار.

 تمييز النص.

 الألوان.

 الجداول.

 الاقتباسات.

 الروابط.

كما تدعم:

 إدراج الصور.

 تحريك الصور داخل الملاحظة.

 كتابة تعليق أسفل كل صورة.

 إدراج أشكال:

 مربع

 دائرة

 سهم

 خط

 نجمة

 أيقونات

مع إمكانية وضع النص والصور والأشكال في نفس الصفحة بحرية.

4) لوحة رسم (Canvas)

مثل السبورة.

يمكن:

 الرسم بالقلم.

 إضافة صور.

 تحريك العناصر.

 تكبير وتصغير.

 الكتابة فوق الصور.

5) المهام (Tasks)

لكل مهمة:

6) الإشعارات الذكية

عند تحديد موعد:

 إرسال إشعار محلي Local Notification.

 ظهور في شاشة الهاتف.

 تأجيل 10 دقائق

 فتح المهمة مباشرة

مع دعم التكرار اليومي والأسبوعي والشهري.

9) المفضلة والتثبيت

يمكن:

10) الأمان

يدعم:

 قفل ببصمة الإصبع.

 قفل برمز PIN سريع (4–6 أرقام).

 قفل تلقائي بعد مدة من عدم الاستخدام.

 إخفاء محتوى الإشعارات على شاشة القفل.

 قفل تصنيفات محددة (مثل "كتابات خاصة") بشكل مستقل.

11) المرفقات

داخل كل ملاحظة يمكن إضافة:

 مواقع جغرافية.

 تسجيلات صوتية (مرحلة لاحقة).

12) التزامن والنسخ الاحتياطي

 مزامنة فورية عبر السحابة.

 نسخ احتياطي تلقائي.

 العمل دون اتصال مع المزامنة عند توفر الإنترنت.

 دعم استخدام الحساب نفسه على الهاتف والتابلت.

13) شاشة التقويم

تعرض:

 المواعيد.

 المهام.

 التذكيرات.

14) شاشة الإحصاءات

تشمل:

 عدد المهام المنجزة.

 عدد المهام المتأخرة.

 نشاط المستخدم أسبوعيًا وشهريًا.

التقنيات المقترحة في Lovable

Frontend: React + TypeScript + Tailwind CSS + shadcn/ui.

المحرر: TipTap أو Lexical مع دعم RTL.

قاعدة البيانات والمزامنة: Supabase.

المصادقة: Supabase Auth.

الإشعارات: Capacitor Local Notifications على Android وiOS.

الأمان البيومتري: Capacitor Biometrics أو Native Biometric API.

التخزين المحلي: IndexedDB/SQLite مع مزامنة لاحقة.

التغليف كتطبيق جوال: Capacitor لإنتاج تطبيقات Android وiOS.

ميزات تميز التطبيق عن Samsung Notes

 تصنيفات مخصصة غير محدودة مع ألوان وأيقونات.

 نظام مهام وتذكيرات متكامل داخل الملاحظات.

 بحث متقدم يشمل النصوص والتعليقات والوسوم.

 قفل بيومتري أو برمز PIN مع إمكانية حماية أقسام محددة.

 محرر يجمع النصوص والصور والأشكال في مساحة عمل واحدة.

 تجربة متجاوبة ومصممة خصيصًا للهواتف والأجهزة اللوحية مع دعم كامل للغة العربية واتجاه RTL.

يجب ان يدعم التطبيق خاصية بي دابليو اي للتثبيت كتطبيق على الهاتف
