# حالة تنفيذ MemoFlow

التاريخ: 11 أكتوبر 2026. نقطة البداية: `a8be3de4d2ef0ca0dc4f35339a5bd8c49767c331`.

## نتيجة المرحلة الأولى

أُعيد تنظيم الاستخدام اليومي حول المذكرات والمهام والخزنة، مع إصلاحات للتنقل والبناء وجلسة الخزنة. هذه نسخة تأسيس للويب، وليست إعلان جاهزية لمدير كلمات مرور أصلي على أندرويد.

| المجال         | المنفّذ                                                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| التنقل         | ثلاثة تبويبات، قائمة جانبية للتابلت، وفتح التفاصيل مباشرة. الصفحة الأولى تفتح المذكرات.                                                          |
| المسارات       | نقل القوائم إلى ملفات `*.index.tsx` حتى لا تمنع عرض التفاصيل. عناوين URL العامة بقيت كما هي.                                                     |
| المظهر         | أسطح هادئة وألوان فاتحة وداكنة، RTL، وتركيز لوحة المفاتيح وتقليل الحركة.                                                                         |
| الخط           | ثمانية ملفات WOFF2 محلية للعربية واللاتينية بأوزان 400–700، وترخيص IBM/OFL. لا حاجة إلى Google Fonts وقت التشغيل.                                |
| المهام         | بحث وفلترة وأولوية وقائمة تحقق. العنوان والبنود داخل المهمة، والخصائص الإضافية في قسم مطوي. إضافة موعد تذكير في التفاصيل.                        |
| صحة المهام     | توحيد `done` و`status` عند الإنجاز؛ تحديث القائمة والتفاصيل؛ تصحيح التكرار الشهري عند نهاية الشهر والتصفية حسب اليوم المحلي.                     |
| الإنشاء        | نموذج مباشر لمذكرة أو مهمة، مع التحقق من العنوان وعرض فشل الحفظ.                                                                                 |
| الخزنة         | مفتاح مقيد بالحساب؛ القفل عند الخروج/تغيير الحساب/إخفاء الصفحة/الخمول خمس دقائق. محاولة فتح قديمة لا تستطيع تجاوز قفل أحدث.                      |
| أخطاء الخزنة   | فشل تحميل الإعدادات لا يعرض إنشاء خزنة بالخطأ؛ فشل حفظ الحساب يبقي النموذج؛ إظهار أخطاء العرض والنسخ والحذف.                                     |
| البصمة القديمة | إيقاف اختصار WebAuthn السابق وحذف قاعدة `mf-vault-bio` التي كانت تخزن مفتاحًا قابلًا للاستخدام بجانب PIN المغلّف. كلمات المرور بالخادم لا تُحذف. |
| الإعدادات      | إزالة الخيارات الشكلية غير المنفذة؛ إبقاء المظهر، طلب إذن التذكيرات، الخزنة، الحساب، والوصول للأقسام القديمة.                                    |
| البناء         | اعتماد Bun وملف قفل واحد؛ تحويل روابط تنزيل الحزم الخاصة إلى السجل العام مع حفظ النسخ والبصمات السابقة؛ إضافة Playwright للاختبارات فقط.         |
| PWA            | إنشاء Service Worker في `.output/public` الصحيح وتضمين الخط في precache؛ إزالة fallback لصفحة ثابتة غير موجودة. هذا لا يوفر قاعدة بيانات محلية.  |

## التحقق المحلي

- تثبيت الحزم من `bun.lock`، وفحص TypeScript، وبناء الإنتاج: نجحت.
- 13 اختبارًا و32 تحققًا لقواعد المهام وجلسة الخزنة والتوافق مع تشفير كلمات المرور القديم وكشف تلف النص المشفر: نجحت.
- اختبار متصفح ببيانات اصطناعية على 390×844 و1024×768: التنقل، البحث، إنجاز مهمة وحقول طلب الحفظ، الإنشاء، المظهر، الوصول للأقسام السابقة، تفاصيل المهمة والتذكير، ومحرر المذكرات وإعادة تحميله.
- اختبار الخزنة: رفض PIN خاطئ، الفتح والعرض، القفل اليدوي وعند إخفاء الصفحة، اختفاء كلمة المرور المكشوفة، واحتفاظ النموذج بمدخلاته عند فشل الحفظ.
- تحميل IBM المحلي، وعدم تجاوز العرض الأفقي في الشاشات المختبرة، وعدم وجود استثناءات JavaScript في تلك التدفقات.
- مراجعة صور الهاتف والتابلت وإصلاح تجاوز عرض نموذج البنود وحقول المواعيد.
- أضيف GitHub Actions للتثبيت الثابت وTypeScript والاختبارات والبناء والمتصفح. نتيجة تشغيله عن بُعد تظهر في Actions؛ النتائج أعلاه محلية.

هذه الفحوص لا تمثل اختبارًا على هاتف أندرويد حقيقي أو تدقيقًا أمنيًا شاملًا. لا تزال رسالة حجم بعض حزم JavaScript الكبيرة تظهر أثناء البناء.

## إضافة المرحلة الثانية — حفظ المذكرات واستعادة المسودات

دُمجت المرحلة الأولى في `main` عبر PR #1 بعد نجاح فحوص GitHub. عالجت هذه الإضافة سبب فقد التعديلات في المحرر القديم: تنفيذ الحفظ عند تنظيف effect ثم استقبال تحديث خادم أقدم فوق النص الحالي.

- عمليات كتابة متسلسلة؛ لا تبدأ كتابة ثانية قبل انتهاء الأولى، ويظل النص الأحدث ظاهرًا ومحفوظًا كمسودة.
- حفظ عنوان المذكرة ونصها محليًا فور التعديل قبل مهلة الإرسال، مع استعادتهما بعد إعادة التحميل وعودة الاتصال.
- مفاتيح مسودات منفصلة حسب الحساب والمذكرة وجلسة التحرير، ونسخ محلية بمعرّفات لا تُعاد كتابتها؛ اكتمال طلب قديم لا يحذف مسودة أحدث.
- كل تحديث إلى Supabase مشروط بمعرّف الحساب والمذكرة و`updated_at` المتوقع. تغيير النص على جهاز آخر يُظهر معاينة وخيارًا صريحًا بدل الكتابة فوقه. تغييرات التثبيت والمفضلة وحدها تسمح بإعادة المحاولة الآمنة.
- استمرار فشل الحفظ يترك النص والمسودة ويعرض زر إعادة المحاولة، وعند عودة الشبكة تُعاد المحاولة تلقائيًا.
- عند تعذر التخزين المحلي، يظهر التحذير ويُطلب تأكيد قبل مغادرة الصفحة إذا لم ينجح الحفظ في الخادم. لا تُعرض حالة حفظ محلي ناجح عند امتلاء المساحة.
- إصلاح تحديث محتوى المحرر عند اختيار نسخة الخادم، وإضافة تأكيد قبل حذف المذكرة ومسودتها.

التحقق الإضافي: مجموع **25 اختبارًا و61 تحققًا** نجحت محليًا، مع TypeScript وESLint للملفات المعنية وبناء الإنتاج. نجحت تدفقات المتصفح السابقة وتدفقات جديدة للتعديل أثناء تأخير الاستجابة، والفشل وإعادة التحميل وإعادة المحاولة، والتعارض وإعادة التحميل واختيار أي من النسختين، وتغير هوية الحساب، وامتلاء التخزين ومنع المغادرة دون تأكيد. تستخدم الاختبارات بيانات اصطناعية واعتراضًا كاملًا للطلبات الخارجية.

المسودات تستخدم `localStorage` وليست قاعدة بيانات التطبيق المحلية النهائية. نص المذكرات فيها غير مشفر، ويمكن فقده إذا مسح المستخدم بيانات الموقع/التطبيق أو نفدت المساحة؛ تُظهر الواجهة أخطاء التخزين. لا يُخزن فيها أي مفتاح خزنة أو كلمة مرور من قسم الخزنة. لا تشمل نسخًا محلية للمرفقات أو المهام أو الخزنة. تسجيل الدخول وفتح المذكرة من البداية ما زالا يحتاجان اتصالًا بالخادم؛ لا يُدّعى تشغيل كامل دون إنترنت.

## حدود النسخة الحالية

1. التخزين ما زال في Supabase؛ الذاكرة المؤقتة وService Worker ليسا SQLite أو قاعدة بيانات محلية موثوقة.
2. تشفير الخزنة القديم ما زال قائمًا للتوافق: كلمة المرور مشفّرة، وبيانات العنوان واسم المستخدم والرابط والملاحظات ليست مشفّرة بالكامل. الرمز ذو الستة أرقام ليس أساسًا كافيًا وحده لخزنة إنتاج مقاومة للتخمين غير المتصل.
3. لا توجد خدمة Autofill أصلية، ولا حفظ من التطبيقات الأخرى، ولا APK/AAB جديد. إعداد `server.url` في Capacitor لم يتغير؛ فصل الوظائف المعتمدة على الخادم يسبق التحويل إلى تطبيق مستقل.
4. لم يُنفّذ بعد تصدير/استيراد نسخة احتياطية مشفّرة أو تكامل منتقي الملفات مع Drive. زر التصدير القديم غير العامل أُزيل.
5. أُصلح تسلسل حفظ المذكرات واستعادة مسوداتها كما سبق. قاعدة البيانات المحلية الكاملة ومعالجة المرفقات والمزامنة المستقلة ما زالت ضمن المرحلة التالية.
6. التقسيمات والبنود القديمة محفوظة في نماذجها الحالية. لم تُنفّذ عملية حذف أو ترحيل مدمرة لجداول المستخدم.
