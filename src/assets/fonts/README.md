# Bundled IBM Plex Sans Arabic

Source: @fontsource/ibm-plex-sans-arabic 5.2.5, IBM Plex (SIL Open Font License).
Arabic and Latin WOFF2 subsets, regular style, weights 400/500/600/700.
Imported locally by src/styles.css; no runtime font CDN requests.

The upstream notice is retained in LICENSE.txt and public/IBM-Plex-OFL.txt.
Windows packaging also includes a readable resources/IBM-Plex-OFL.txt alongside
the ASAR archive. License source:
https://github.com/google/fonts/blob/main/ofl/ibmplexsansarabic/OFL.txt
